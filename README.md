Aspiring Electrical & Computer Engineer • Student Developer • Creator of Dragon Academy

Dragon Academy is an offline-first study platform for Cambridge O-Level / IGCSE learners. It helps students practice exam-style questions, track weak topics, and study offline with a desktop-style experience.

## 🚀 Project status
- Version: v1.6.8 · Phase 4 (release published)

## Key goals
- Offline-first access to study materials and question banks
- Structured questions by subject, chapter, topic, and difficulty
- Exam-style practice and revision workflows
- Support for multiple question types (MCQ, structured questions)
- Integrated Python coding environment for Computer Science practice
